# visual RSI studio：四项验证

更新：2026-11-19。用一次实际任务检查四件事，不另设立项、访谈或商业化流程。

1. **可视化**：能否看到真实控制会话和画面？能否在支持引导的执行器中传递用户指令，并确认何时生效？历史内容明确标识。
2. **数据管理**：运行后能否找到当时的配置、版本、过程与结果？新会话能否继续查看？失败、中断和缺失内容是否保留？
3. **环境注册**：能否登记一个实际环境，检查依赖与连接，之后直接选择并启动？可从“环境注册”选择 checkout 和解释器，再加入工作区观察配置。已用 LIBERO、LIBERO-Pro 实测重置和取帧。
4. **实际效果**：任务是否按要求完成？修改前后在可比较条件下效果和耗时如何？记录人工介入和等待，工作台好用程度与算法成绩分别判断。

每次只保留：任务、环境与方案版本、操作、实际结果、问题、下一步。没有执行的项目标为未验证；开发自检和真实任务分开。

现有 HexaShell / Push-T 项目可作为首个检查对象。使用原配置和预算；本说明不表示本轮已经启动了机器人或模型评测。

在示例工作区选择 Push-T 消融，核对父版本与当前版本同一场景的判定、步数、实际工具调用和原生报告。完整环境验证状态见[接入指南](rsi-board.md)。
