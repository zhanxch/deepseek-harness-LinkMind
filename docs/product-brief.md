# visual RSI studio

更新：2026-11-18。按用户要求收敛定位，替代此前复杂的 FDE 与商业验证规划。

**用于具身 Agent 的可视化工作台。重点：可视化、数据管理、环境注册、实际效果。**

## 1. 可视化

在原生会话中看真实控制过程、工具调用和摄像头，必要时发出引导。文件和其他会话可同时查看，保持熟悉的 DSH 操作方式。

当前已有控制事件与相机快照显示；外部方案插话依赖适配器，历史画面与对话还不能完整同步回放。

## 2. 数据管理

以每次运行为单位，关联输入、配置、代码版本、轨迹、画面、结果和人工介入。能找到上次用了什么，也能比较修改前后；失败和中断一并保留。

当前保存了部分来源、配置和运行结果。完整数据归档与交接还需完善，哈希不等于文件已保存。

## 3. 环境注册

让用户接入已有仿真或真实环境，登记其入口、依赖、资源、连接与检查结果，之后可以直接选择使用。环境与具体方案分开，同一环境可运行不同方案；助手可以协助完成登记。

当前工作区注册和运行配置不是完整的环境注册。下一步优先补好一个实际可用环境的登记、检查与选择。

## 4. 实际效果

用真实任务检查是否完成、评分和耗时，再比较修改前后结果与使用便利程度。工作台效果和控制算法成绩分开记录，缺失数据不补造。

## 使用路径

选工作区与环境 → 在会话中启动 → 看过程与引导 → 保存数据 → 比较效果。
