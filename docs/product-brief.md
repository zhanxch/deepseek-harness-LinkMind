# visual RSI studio

更新：2026-11-19。按用户要求收敛定位，替代此前复杂的 FDE 与商业验证规划。

**用于具身 Agent 的可视化工作台。重点：可视化、数据管理、环境注册、实际效果。**

## 1. 可视化

在原生会话中看真实控制过程、工具调用和摄像头，必要时发出引导。文件和其他会话可同时查看，保持熟悉的 DSH 操作方式。

Agent RSI Board 将每轮的假设、版本改动、测量和决定与父轮关联，支持分支和跨会话查看。打开某轮的运行可以回到对应控制过程和相机。外部方案的实时引导取决于适配器。

## 2. 数据管理

以每次运行为单位，关联输入、配置、代码版本、轨迹、画面、结果和人工介入。能找到上次用了什么，也能比较修改前后；失败和中断一并保留。

当前保存了部分来源、配置和运行结果。完整数据归档与交接还需完善，哈希不等于文件已保存。

## 3. 环境注册

让用户接入已有仿真或真实环境，登记其入口、依赖、资源、连接与检查结果，之后可以直接选择使用。环境与具体方案分开，同一环境可运行不同方案；助手可以协助完成登记。

0.9.0 可注册本地 checkout、绑定独立解释器、检查资源，并在项目间复用。已接入四个仿真器，开放统一的自定义环境清单。[注册与验证范围](rsi-board.md)

## 4. 实际效果

用真实任务检查是否完成、评分和耗时，再比较修改前后结果与使用便利程度。工作台效果和控制算法成绩分开记录，缺失数据不补造。

## 使用路径

选工作区与环境 → 在会话中启动 → 看过程与引导 → 保存数据 → 比较效果。

接下来先完成这一条路径，功能按上述四点整理。LinkMind 保留为研究方案名称；本工作台使用 visual RSI studio。当前版本的具体能力见 [README](../README.md)，简单检查方式见 [四项验证](product-validation.md)。
